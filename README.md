功能介绍：

1、宏软代码助手用时自动呼之即出，不用时自动缩回到桌面的顶部，似QQ程序，不遮挡其它程序窗口，可以在任意程序窗口的编辑光标处精准插入文本（字符、代码、数据、资料…），适合所有行业办公、科研、医疗、教育教学、辅导需求，提高工作效率。
2、将你的资料文本内容存放到记事本文件中（*.txt）,然后复制到当前程序下的“Code”文件夹下，在“Code”文件夹下可以根据需要自行创建多级文件夹，用于存放你的资料文本文件。
3、不同类别的资料放在不同的文件夹中，依文件夹进行分类。
4、插入助手：在“宏软代码助手.exe”程序位置要有一个根文件夹“Code”，本程序从这个文件夹自动搜索、添加资料分类文件夹到“代码类别列表”中，点击“代码类别列表”中任一项，就会将这个文件夹下的所有代码文本文件加载到代码列表中，在“代码列表”中选择你所需代码，就会将代码文本内容加载到“代码预览”文本框中，点击“插入代码”按钮，就会将代码文本内容快速、经准地插入到你的目标窗口的编辑光标位置。
5、封装助手：仅适合将Excel、PowerPoint、Word、WPS等Office程序的VBA代码转换为VB6.0、VB.net的封装代码，便于VB6.0、VB.net对VBA代码的封装。
6、代码助手：主要是对代码格式化操作、代码的编辑、代码的语句的批量增删。
7、编码转换：是对记事本文件ANSI、UTF-8编码格式化的快速转换。
